# Personal Finance Tracker

A simple, responsive personal finance tracker that helps users record their income and expenses, organise transactions by category, and keep track of their current balance.

## Who It Is For

The app is designed for individuals who want a simple way to keep track of their everyday finances without using a complicated budgeting application.

## Problem It Solves

Managing personal finances can become difficult when income and expenses are spread across different transactions.

This app provides a simple view of:

* Total income
* Total expenses
* Current balance
* Individual transactions
* Transaction categories

Users can add and remove transactions while keeping their financial information organised in one place.

## Core Features

* Add income transactions
* Add expense transactions
* Enter transaction names and amounts
* Categorise transactions
* View transaction history
* View total income
* View total expenses
* View current balance
* Delete transactions
* Save transactions using local storage
* Responsive layout for desktop and mobile
* Basic form validation
* Empty states when no transactions exist

## Important Decisions

### Keep the scope small

The initial prompt focused on the core functionality of a personal finance tracker. I intentionally avoided features such as authentication, payments, bank integrations, and a backend because they were not necessary for the first version.

### Use local storage

I chose local storage so that users can keep their transactions when they refresh or reopen the application without requiring a backend database.

### Responsive design

The application is designed to work on both desktop and mobile devices because users may want to check or update their finances from different devices.

### Build incrementally

Rather than trying to build every feature at once, I developed the application in smaller stages. This made it easier to test individual features, identify problems, and make targeted improvements.
