Day 1: Project Setup
Starting Prompt

I started the project with a basic prompt:

Build a simple responsive personal finance tracker. Users should be able to add income and expense transactions, categorise them, view their transaction history, see total income, total expenses and current balance, and delete transactions. Use a clean, modern interface that works on desktop and mobile.

Initial Approach

I decided to keep the application focused on the core requirements from the prompt.

The first version will allow users to:

Add income
Add expenses
Categorise transactions
View transaction history
View total income
View total expenses
View their current balance
Delete transactions

I decided not to add authentication, payments, bank integrations, or a backend because these features are not required for the core application.

Technology Decisions

I chose React and JavaScript for the application because they provide a good foundation for building an interactive user interface.

I also decided to use local storage to persist transactions between page refreshes without introducing a backend.

Initial Design Decision

I wanted the interface to be clean and easy to understand.

The main dashboard will prioritise the user's financial summary, followed by the transaction form and transaction history.

The layout will also adapt to smaller screens.

Development Progress

The initial project structure and application interface were created.

The next step is to test the first version and identify any functionality or usability issues.
